## What ran live

The operator controller used the existing `OPS_TOKEN`, exact app/origin/guild/channel checks, a fixed game/queue and verified participant list, bounded action names, deterministic action receipts, and a fixed expiry. It rejected fixture players involved in another queue/match and unexpected players in the demo queue. Player actions used the ordinary match engine, with normal captain checks; fixed organizer actions seeded history and added players. No Discord user authentication was forged.

The controller existed only in an external temporary entrypoint. The final deployment uses `src/worker.ts` directly. Its former endpoint now returns HTTP 404. The temporary version also has an independent expiry at `2026-10-27T04:53:56.464Z`; it must not be restored or extended for future demos.

The demo used custom game `7404ce1e-aeb5-4748-ab95-a06e5825a6a3` and non-default queue `17120cfa-645a-4c92-aaee-5409b68e4ac1`. Ten existing Discord member identities represented simulated participants/spectators, with ratings and gold isolated in this demo game. Three explicitly synthetic historical wins made the existing streak stories visible. No synthetic lobby evidence was submitted.

## Remaining acceptance gates

There is no credential, approval or deployment blocker left. These checks require real gameplay or human interaction:

1. An actual AoE2 game with reviewed profile mappings: attach its lobby, verify the join link, observe genuine start/end evidence, restart while tracking, and receive exactly one manual-result prompt. No real lobby was available in this automated demo. A read-only public profile lookup from this environment returned HTTP 200 and the expected profile ID, but does not prove ownership or live match behavior.
2. Human Discord slash/button interactions, private ephemeral panels and browser OAuth sign-in. Handler/signature tests and operator-driven actions do not establish end-to-end human interaction acceptance.
3. Provider publication lag, bot processing/delivery latency and attributable active/idle cost. These were not measured here. Live occupancy remains unavailable.

Automatic betting closure, civilization picking and additional AoE2-specific banter are later backlog phases. This demo used manual betting closure, map voting and existing generic stories. Other games remain manual until their adapters are implemented. Do not mark those later phases complete from this run.
